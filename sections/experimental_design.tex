\subsection{Forecasting task}
\label{sec:exp:task}

% SCHREIBE: Absatz Prognoseaufgabe (5-7 Sätze).
%  - Was die Modelle ausgeben: für jedes Land i und jeden Entscheidungsmonat
%    t drei bedingte Quantile der Spread-Änderung Delta s_{i,t+1} einen
%    Monat voraus, auf den Stufen {0.1, 0.5, 0.9}.
%  - Daraus wird das zentrale 80%-Prognoseintervall, also alpha = 0.20.
%    Das 0.5-Quantil ist der Punktschätzer.
%  - WARUM ausgerechnet {0.1, 0.9} — das ist eine Designentscheidung, die
%    du begründen musst: TiRex und TiRex-2 geben nur Dezile aus. 0.1 und
%    0.9 sind damit die breitesten Stufen, die JEDES Modell im Vergleich
%    ohne Extrapolation liefern kann. Die Wahl richtet sich also nach dem
%    schwächsten Glied der Vergleichskette, nicht nach Bequemlichkeit.
%  - Die trainierten Quantilmodelle (die Deep Models und LightGBM) werden
%    mit dem Pinball-Loss gefittet. Die Gleichung \eqref{eq:pinball} steht
%    schon da, sie bleibt unverändert — ein Satz Hinführung reicht.
%  - Die Punktprognosemodelle (Random Walk, ARIMA) haben keinen Quantil-
%    Loss. Sie bauen ihr Intervall aus den empirischen Quantilen ihrer
%    In-Sample-Residuen, die auf die Punktprognose addiert werden.
%  - PFLICHT: dazusagen, dass das ohne Verteilungsannahme auskommt. Das
%    ist der Grund, warum es zum verteilungsfreien Anspruch der Arbeit
%    passt, und kein Nebensatz.
%  NICHT hier: wie kalibriert wird (das ist \cref{sec:conformal}) und wie
%  ausgewertet wird (das ist \cref{sec:evaluation}).

For every country i and every month t three quantiles (0.1, 0.5, 0.9) for the change in spread $\Delta s_{i,t+1}$ with respect to the next month are predicted.
From the lower and upper quantile we create the 80$\%$ prediction intervall, so $\alpha =0.2$. The 0.5 quantile is our point estimator. TiRex and TiRex2 only output deciles. For that reason we choose the widest possible quantiles all models could be compared on and endet up with 0.1 and 0.9. The trained Models, neural networks and lightgbm, are trained on the pinball loss:
\begin{equation}
  \mathcal{L}(\hat{q}, y) \;=\;
  \frac{1}{|\mathcal{T}|}\sum_{\tau \in \mathcal{T}}
  \max\!\big(\tau\,(y - \hat{q}_\tau),\; (\tau - 1)(y - \hat{q}_\tau)\big).
  \label{eq:pinball}
\end{equation}
The Models that only produce a pointforecast (Random Walk, ARIMA) dont have a quantile loss. We create their prediction intervalls from the respective impirical quantiles of their in sample residuals that are added onto the pointforecast. This works without an distribution assumption.

\subsection{Training regimes}
\label{sec:exp:regimes}

% SCHREIBE: Kurzer Führungssatz + die drei Regime + zwei Sätze Einordnung.
%  Die \begin{itemize} mit L / G / GF bleibt strukturell stehen, du
%  schreibst den Rahmen und die Erläuterungen darin neu.
%  - L (local): ein Modell pro Land, bis zu 277 Monatsbeobachtungen.
%  - G (global): ein Modell auf dem gepoolten Panel, bis zu 2770
%    Ländermonate. Die Länderidentität geht mit hinein — als gelerntes
%    Embedding bei den neuronalen Netzen, als native kategoriale Variable
%    bei LightGBM.
%  - GF (global fine-tuned): das globale Modell wird je Land vollständig
%    feingetunt, mit einem Zehntel der globalen Lernrate.
%  - WARUM diese drei und nicht zwei: sie spannen genau die Achse lokal ->
%    global -> spezialisiert auf. Das ist die Achse, an der RQ1 hängt.
%    Ein Satz dazu, dass der Vergleich dadurch fair wird, weil sich die
%    drei Regime nur in dieser einen Dimension unterscheiden.
%  - Abgrenzung zum Schluss: LightGBM hat nur L und G (Begründung kommt
%    erst in Block 7, hier nur die Tatsache). Die klassischen und die
%    Zero-Shot-Modelle laufen in einer einzigen Einstellung.
%    Querverweis \cref{tab:model_selection}.

We employ three training regimes per Model where possible. 
\begin{itemize}
  \item \textbf{L} (local): One Model per country that is trained up to 277 monthly observations.
  \item \textbf{G} (global): One Model on the pooled panel trained on up to 2770 months, 277 per country. Country is a learned embedding in the neural networks and a native category in lightgbm. 
  \item \textbf{GF} (global fine-tuned): The global modell is fully fine tuned per country with a tenth of of the learning rate.
\end{itemize}
We choose this design because it allows a fair comparison between a local, a global and a spezialiced model. For lightgbm there is no fine tuning equivalent so we only employ the L and G regimes here. The classical and zero shot models have a single configuration (\cref{tab:model_selection}).

\subsection{Input sequences and scaling}
\label{sec:exp:sequences}

% SCHREIBE: Absatz Eingabe und Skalierung (4-5 Sätze).
%  - Was das Modell sieht: die Sequenz der letzten W monatlichen
%    Feature-Vektoren bis zum Entscheidungsmonat t. Daraus wird
%    Delta s_{t+1} geschätzt.
%  - Skalierung: z-Standardisierung pro Land und pro Feature, das Target
%    eingeschlossen.
%  - PFLICHT (das ist der eigentliche Punkt des Absatzes): der Skalierer
%    wird NUR auf dem Trainingsfenster des jeweiligen Refits gefittet.
%    Deshalb kann keine Zukunftsinformation über die Skalierung
%    hereinlecken. Ohne diesen Satz ist der ganze Absatz Beiwerk.
%  - Der eine fehlende Input (Griechenland 2015-07) wird um einen Monat
%    vorgetragen. Target und Evaluation werden NIE imputiert. Diesen
%    Unterschied klar benennen, er kommt in \cref{sec:conformal} wieder.
%  - Querverweis auf \cref{sec:data} für die Datenlücke selbst.

The forcast is done on the last W monthly feature vectors up to the decition month t. From that $\Delta s_{i,t+1}$ is estiamted. The input data is z standardised per country and feature, the target included. The standartisation is exclusively done on the trainings data of the current refit so there is no data leakage. The one missing input (Griechenland 2015-07) is forward filled \cref{sec:data}. Target and evaluation are never imputed.

\label{sec:exp:refit}

%    Modell die Monate C+1 bis C+12, jeweils einen Schritt voraus und
%    jeweils nur mit den zu diesem Zeitpunkt verfügbaren Daten.
%  - Die ersten 114 Monate sind das minimale Trainingsset.
%  - Die Monate 115-150 haben eine DOPPELROLLE, und die gehört explizit

All models are refit every 12 months on an expanding train set. At train cutoff in month C the same model predicts the months C+1 to C+12 in one step ahead predictions using only the date availabe at the respective point in time. The first 114 months are minimal train set. The burn in set, months 115 to 150, serve as calibration set for the conformal methods (\cref{sec:conformal}) aswell as validation set for the hyperparameter optimisation. Months 151 to 277 are the test window, so 127 test months per country. The 127 months are months all the results in the results chapter are based on \cref{tab:refit_blocks}.

The months 1 to 114 are used for training and the months 115 to 150 for validation. This stays consistent for all trained models. After that the Hyperparameters are frozen and the models retrained with the same set every time. No data from a test window is used in the selection. Every trainable model with information horizon is caped to at max 24 months so no model can see further back than the others. TiRex and TiRex2 see the full expanding level history. The 24 month cap doesent apply to them. This is an inforamtion advantage for the zero shot models. The hyperparameter selectionw as done by minimising the average pinball loss on the standartised delta scale, averaged over all countrys, on the burn in/ validation set. The use the standardised scale since otherwise countrys with higher spread niveaus would dominate the selection.

\subsection{Seeds and aggregation}
\label{sec:exp:seeds}
Only the neural models, xLSTM and LSTM, use the three seeds (42, 43, 44). With
them we measure how much of the result is training randomness. Coverage is
reported as mean $\pm$ sd across seeds, and downstream we also report the span
of the median skill across seeds as a robustness check. The hyperparameters are
tuned once at seed 42 (\cref{sec:exp:hpo}) and then frozen, so the seeds only
differ in the production refits. The run loop iterates L, G, GF $\times$ blocks
$\times$ seeds. Every seed is its own independent refit/predict chain and keeps
its seed label on every prediction row through the conformal and diagnostic
stages. Predictions are never pooled across seeds before the per-chain metrics
are computed. The level-scale metrics (Winkler score, pinball loss, average
width, and median MAE) are computed per country, so per regime, seed, and
country, since otherwise a single high-spread country would dominate the
aggregate. Only the scale-free metrics, mean coverage rate and mean crossing
rate, are averaged across countries; this is the sole cross-country
aggregation. The remaining models, RW, ARIMA, LightGBM, TiRex, and TiRex-2,
are deterministic and run with a single seed.



\subsection{Quantile post-processing}
\label{sec:exp:rearrange}
The three quantiles are estimated independently, so they can cross. Crossed
quantiles would leave the conformal layer downstream with ill-defined interval
bounds. That is why we sort the three values per forecast before evaluation, a
monotone rearrangement \parencite{chernozhukov2010} that guarantees
$\hat{q}_{0.1} \le \hat{q}_{0.5} \le \hat{q}_{0.9}$. How often the raw
quantiles crossed before sorting is logged as a diagnostic and reported per
model. This step is the same for every model.

\subsection{Conformal prediction layer}
\label{sec:exp:conformal-ref}
The benchmarks emit only raw quantiles and contain no calibration code. The
conformal layer runs downstream on every combination of model, regime, seed, and
country. All methods share one nonconformity score, the CQR score
$E_t = \max(\hat{q}_{\mathrm{lo},t} - y_t,\; y_t - \hat{q}_{\mathrm{hi},t})$,
calibrated on a rolling out-of-sample pool. Since the same set of methods is
applied to every model, differences in interval quality can be traced back to
the models and not to the calibration. The methods, their fixed parameters, and
the calibration-pool variants are described in \cref{sec:conformal}.
